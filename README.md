# PhytoClean — Social Links

A simple, mobile-friendly landing page for PhytoClean's public social and contact links.

The project is in development. This page is a contact hub, not a product sales page.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. Wait for GitHub Pages to publish the site.

The public page URL should be: https://meh dib11.github.io/phytoclean-social/ (remove the space in the username; expected URL: https://mehdib11.github.io/phytoclean-social/)
